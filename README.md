# Task Manager (Simple CLI Application)

A simple and lightweight command-line Task Management application built with **Python**, designed to manage daily tasks efficiently with local JSON file persistence.

---

## Features

- **Add Task:** Create new tasks with an automatically generated unique ID.
- **View Tasks:** Display the complete list of tasks along with their current status (`[Done]` or `[Pending]`).
- **Toggle Status:** Easily switch a task's status between completed and pending.
- **Delete Task:** Remove any task by specifying its unique ID.
- **Data Persistence:** Automatically saves and loads all tasks from a local JSON file (`data/tasks.json`).
